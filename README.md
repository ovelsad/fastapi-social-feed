## FastAPI Social Feed API

REST API-сервис для социальной ленты на **FastAPI** + **SQLAlchemy** с подключением к **PostgreSQL**.
Сервис моделирует взаимодействие пользователей с постами (просмотры и лайки): отдает данные
о пользователях, постах и действиях, а также строит простую систему рекомендаций по популярности.

Проект демонстрирует:
- работу с ORM-моделями SQLAlchemy поверх реальной БД;
- построение REST API по проверенным практикам (Pydantic-схемы, корректные status-коды, обработка ошибок);
- агрегацию пользовательских взаимодействий для формирования ленты рекомендаций.

---

### Структура проекта

```
final/
├── app.py          точки входа REST API (эндпоинты FastAPI)
├── database.py     движок, сессия и базовый класс ORM
├── schema.py       Pydantic-схемы ответов (UserGet, PostGet, FeedGet)
├── table_user.py   ORM-модель User       (таблица user)
├── table_post.py   ORM-модель Post       (таблица post)
└── table_feed.py   ORM-модель Feed       (таблица feed_action)
```

---

### Модель данных

- **User** - пользователь: возраст, город, страна, экспериментальная группа, пол, ОС, источник трафика.
- **Post** - пост: текст и тема (`topic`).
- **Feed** - действие пользователя над постом: составной ключ `user_id + post_id`, время и тип действия
  (`view` / `like`). Через `relationship` подтягивает связанные `User` и `Post`.

---

### Эндпоинты

| Метод и путь                          | Описание                                                        |
|---------------------------------------|----------------------------------------------------------------|
| `GET /user/{id}`                      | данные пользователя (404, если не найден)                       |
| `GET /post/{id}`                      | данные поста (404, если не найден)                              |
| `GET /user/{id}/feed?limit=10`        | последние действия пользователя, свежие сверху                  |
| `GET /post/{id}/feed?limit=10`        | последние действия по конкретному посту                         |
| `GET /post/recommendations/?limit=10` | топ постов по числу лайков (рекомендации по популярности)       |

### Запуск

1. Установить зависимости:

   ```bash
   pip install -r requirements
   ```

2. Указать строку подключения к базе через переменную окружения `DATABASE_URL`:

   ```bash
   export DATABASE_URL="postgresql://user:password@host:5432/dbname"
   ```

   Если переменная не задана, используется значение по умолчанию из `database.py`.

3. Запустить сервер:

   ```bash
   cd final
   uvicorn app:app --reload
   ```

4. Интерактивная документация (Swagger UI): `http://127.0.0.1:8000/docs`
